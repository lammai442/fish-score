# FishScore

FishScore is a mobile-first web application for fishing competitions where teams register catches, track events, and follow live-updated scoreboards based on total catch weight.

---

## Purpose

The purpose of FishScore is to replace spreadsheets and chat-based updates with a single platform for managing fishing competitions. The application focuses on real-time updates, simple data entry, and clear visual overviews of competition results.

---

## Features

### Core features

- User authentication
- Create and join teams
- Create and manage competition events
- Register and edit fish catches
- Live-updated scoreboard based on total catch weight

### Optional features

- Heaviest catch per event
- Event deadline handling
- Image upload for catches
